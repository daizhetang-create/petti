# PetTI · 宠物行为人格鉴定实验室

> 给你家小祖宗建一份精神档案。基于日常行为观察,从 6 个维度生成又准又离谱的宠物行为人格档案 —— 像给宠物做的 MBTI。

一个**纯前端、零依赖**的单页应用,打开 `index.html` 即可运行,无需安装、无需后端、无需任何 API key。

## 玩法
回答几个关于你家猫/狗日常行为的问题,PetTI 会从 6 个维度,生成它独一无二的"行为人格档案"。

## 本地运行
直接双击 `index.html`,或用任意静态服务器打开即可。
